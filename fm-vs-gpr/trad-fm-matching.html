2. Matching procedure

Implemented in fm-vs-gpr/merge_fm_to_root.py.

  1. Event. FM row (segment, entry) ↔ file OutDir<segment>, tree entry <entry>. In the CSV, each (segment, entry) maps one-to-one onto (batch_idx, sample_idx_in_batch), and point_idx runs 0..n−1 within each event. runnumber = 21 matches "run21" in the file name. evtnumber is 0 in every entry, so it can't be used as a key.
  2. Cluster. FM points are stored in a different order from the ROOT clusters, so they are matched by position. For each FM point, find the nearest TPC reco cluster (reco_cluster_detid == 2) in (reco_cluster_x, y, z) with a KD-tree. A match is accepted if the distance is < 1e-3 cm and no other point claims the same cluster.
  3. Cross-checks per match. E == reco_cluster_E and seg_target == reco_cluster_g4hit_trkid (counted and reported; both agree 100%).
  4. Seed → clusters. A seed's cluster keys are tpc_seeds_clusters[start_idx : start_idx + nclusters], looked up in reco_cluster_id. start_idx is the running sum of nclusters (checked per event).
  5. Seed FM score. The mean of the per-cluster FM probabilities over the seed's clusters that have an FM score; tpc_seeds_fm_nclusters_scored counts them.
Match quality (all 25 segments): 16,979,350 / 16,979,350 FM points matched; maximum distance 5.05e-5 cm (CSV float rounding); 0 duplicate claims; 0 energy mismatches; 0 track-id mismatches; 0 seed keys missing from reco_cluster_id. 4,373,248 / 5,182,228 seed clusters (84.4%) have an FM score.

Coverage

  • Events: 19,725 of 25,000 are in the FM CSV. 4,195 of the 5,275 missing events have fewer than 50 TPC clusters (FM's smallest event has exactly 50 points). The rest of the missing events include the largest ones (FM's largest event has 3,200 points). This looks like a size selection in the FM data preparation but is not confirmed.
  • Clusters: FM points are TPC clusters only. FM scores 98.9% of primary-particle TPC clusters and 86.1% of secondary-particle ones (see §7).

4. How to use the merged files

Python (uproot)

import uproot, awkward as ak, numpy as np
t = uproot.open("/sphenix/user/hwyu/calotrack_tree/macro/dedx-v2/"
                "fm-merged-run21-25seg/OutDir0_calotrkana_fm.root")["T"]
a = t.arrays(["fm_has_event", "tpc_seeds_maxparticle_pid", "tpc_seeds_maxparticle_p",
              "tpc_seeds_dedx", "tpc_seeds_fm_nclusters_scored",
              "tpc_seeds_fm_pid_prob_1", "tpc_seeds_fm_pid_prob_2", "tpc_seeds_fm_pid_prob_3"])
ok = (a.fm_has_event == 1) & (a.tpc_seeds_fm_nclusters_scored > 0)   # seeds with an FM score
pK = a.tpc_seeds_fm_pid_prob_2[ok]                                     # per-seed FM kaon probability
# FM score used in the comparison: renormalise over pi/K/p
s = a.tpc_seeds_fm_pid_prob_1 + a.tpc_seeds_fm_pid_prob_2 + a.tpc_seeds_fm_pid_prob_3
score_K = (a.tpc_seeds_fm_pid_prob_2 / s)[ok]

ROOT (C++) friend tree

TFile f("/sphenix/user/shuhangli/calotrack_tree/macro/condor_pid_x10/OutDir0/calotrkana.root");
TTree* T = (TTree*)f.Get("T");
T->AddFriend("F=T", "/sphenix/user/hwyu/calotrack_tree/macro/dedx-v2/fm-merged-run21-25seg/OutDir0_calotrkana_fm.root");
// FM kaon probability of reco seeds whose best-match truth particle is a kaon
T->Draw("F.tpc_seeds_fm_pid_prob_2",
        "F.fm_has_event && abs(tpc_seeds_maxparticle_pid)==321 && F.tpc_seeds_fm_nclusters_scored>0");

For all 25 segments, build a TChain of the original files and a second TChain of the merged files in the same segment order, then call AddFriend on the chain.

Conventions to remember: −1 means "no FM score" for every *_fm_pid_prob_* branch; always require fm_has_event == 1 and tpc_seeds_fm_nclusters_scored > 0 before using seed FM scores.

6. How the AUCs and errors are computed

ROC and AUC

One-vs-rest among π/K/p: for species c, positives are the seeds labelled c and negatives are the seeds labelled with the other two species, in the same momentum bin (and the same origin/purity subset where applicable). A single routine, roc_curve_np() in fm-vs-gpr/compare_pid_roc.py, is used for both methods: seeds are sorted by score (descending), TPR/FPR are accumulated at each distinct score threshold, and the AUC is the trapezoidal area under (FPR, TPR).

Statistical error (Hanley–McNeil 1982)

auc_se() in fm-vs-gpr/seed_purity_study.py. With A = AUC, N₊ = number of positives, N₋ = number of negatives:

Q1 = A / (2 − A)    Q2 = 2A² / (1 + A)
SE(A) = sqrt( [ A(1−A) + (N₊−1)(Q1 − A²) + (N₋−1)(Q2 − A²) ] / (N₊ · N₋) )

Example (GPR, primary-seed kaons in [1,2)): A = 0.631, N₊ = 1,070, N₋ = 6,602 → SE ≈ 0.0097.

These are statistical errors only. They assume independent seeds and don't include systematics (GPR training, FM model variation). FM and GPR are evaluated on the same seeds, so their errors are correlated; combining them in quadrature overestimates the error on the FM − GPR difference. A paired test (DeLong or an event-level bootstrap) would be the rigorous way to quote that difference.

7. Primary / secondary split and seed purity

Script: fm-vs-gpr/seed_purity_study.py (output in fm-vs-gpr-2026-10-05-seed-purity/).

  • Truth track of a cluster: reco_cluster_g4hit_trkid from the original trees. Negative ids are G4 secondaries (all present in the event's particle table) and count as real particles; 0 means no truth (about 2% of TPC clusters).
  • Top truth track of a seed: the most common non-zero track id among the seed's clusters. Its PID equals tpc_seeds_maxparticle_pid for 99.96% of seeds.
  • Origin: primary if the top track id > 0, secondary if < 0. 33.3% of the selected seeds are secondary.
  • Seed purity: (seed clusters from the top track) / (seed nclusters).
  • AUC by origin: the selected seeds are split by origin, then the one-vs-rest AUC and its Hanley–McNeil error are computed per species within each momentum bin (§6).

Summary

  • On the same seeds, FM is better than or equal to GPR in 5 of the 6 species × bin combinations within the GPR fit range; the exception is kaons in [1,2).
  • Seed purity is high and doesn't change the FM–GPR ordering.
  • A third of the seeds are secondaries, about half of them protons; FM is particularly strong for secondary pions. On primary seeds, FM and GPR agree within ~1–2σ in [0.8,1.2), and GPR is better for kaons in [1,2) (0.631 vs 0.587).

10. Validation

  • Matching: every FM point matched, with the energy and track-id cross-checks at 100% (§2).
  • Merged file (segment 0): all 11 copied branches identical to the original; per-truth-track FM means rebuilt from the ROOT file equal the CSV for all 12,120 tracks (≤ 1.2e-7); per-seed means equal an independent plain-loop recomputation (162 seeds, ≤ 2.4e-7); the file works as a ROOT friend tree with aligned entries and seed counts.
  • Same-seed GPR: with --no-require-fm (all seeds), the GPR AUCs and counts are identical to the earlier GPR evaluation on OutDir0–24 in all three bins.
  • Refactors: the plotting/selection refactor of compare_pid_roc.py and the table-building refactor of compare_same_seeds.py both reproduce their earlier outputs pixel-identically.

11. Caveats and open questions

  • The GPR evaluation sample (OutDir0–24) is also part of the GPR training sample (OutDir0–999, 2.5% overlap); kept on purpose, expected to be negligible for a smooth 1-D band fit.
  • The earlier truth-track FM comparisons kept only seg_target > 0, i.e. primary truth tracks, and are not directly comparable to the all-seed numbers here.
  • FM kaons on primary seeds in [1,2) (0.587) are well below FM kaons on primary truth tracks (0.700). Open question: is it the seed-cluster averaging (vs. the full truth track) or the seed population? Scoring the primary seeds with their truth track's full-track FM score would separate the two.
  • The reason for the 5,275 events missing from the FM CSV (a likely event-size selection) should be confirmed with Gabor.
